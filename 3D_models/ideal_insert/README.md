## Description

This folder contains a 3D model of the ideal insert.
- The issue with Corning Transwell inserts is that its design is not compatible with the insert/multi holder and generally more troublesome for handling.
- Whereas the issue with Greiner ThinCerts is that it requires complete filling of the well if you want to have a shared medium between the apical and basal compartments.
The ideal insert addresses both issues. In addition, the field of transwells needs a "black" variant for easier masking of fluorescence images.
